# Мультиязычность (i18n)

> Поддержка нескольких языков в Telegram Mini App и боте на основе `language_code` пользователя.

## Концепция

Telegram передаёт `language_code` в `initData` (frontend) и в `Message.from` (bot) — язык определяется автоматически без дополнительного UX.

```
Telegram User → language_code: "ru" | "en" | ...
                      │                    │
               Frontend (React)       Bot (Java)
               react-i18next     Spring MessageSource
               locales/*.json    i18n/messages*.properties
```

- **Fallback**: `en` — при любом неподдерживаемом языке
- **Расширение**: добавить новый язык = добавить один файл
- **Нет хранения в Redis** — язык берётся из Telegram-контекста при каждом запросе

| Код | Язык | Статус |
|-----|------|--------|
| `en` | English | ✅ Fallback |
| `ru` | Русский | ✅ Основной |
| `ar` | العربية | Файлы добавлены, подключение — карточка I18N-NEW-LANGS |
| `de` | Deutsch | Файлы добавлены, подключение — карточка I18N-NEW-LANGS |
| `es` | Español | Файлы добавлены, подключение — карточка I18N-NEW-LANGS |
| `fr` | Français | Файлы добавлены, подключение — карточка I18N-NEW-LANGS |
| `uk` | Українська | Файлы добавлены (код языка по ISO 639-1 — uk), подключение — карточка I18N-NEW-LANGS |
| `zh` / `zh-CN` | 简体中文 | Файлы добавлены, подключение — карточка I18N-NEW-LANGS |

## Frontend: react-i18next

### Установка

```bash
npm install i18next react-i18next
```

### Файлы

```
frontend/src/i18n/
├── index.ts               # инициализация
└── locales/
    ├── en.json            # source of truth
    └── ru.json
```

### Инициализация (`src/i18n/index.ts`)

```typescript
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import WebApp from '@twa-dev/sdk';
import en from './locales/en.json';
import ru from './locales/ru.json';

i18n.use(initReactI18next).init({
  resources: { en: { translation: en }, ru: { translation: ru } },
  lng: WebApp.initDataUnsafe.user?.language_code ?? 'en',
  fallbackLng: 'en',
  interpolation: { escapeValue: false },
});
export default i18n;
```

Подключить в `src/main.tsx` до рендера: `import './i18n';`

### Использование в компонентах

```typescript
const { t } = useTranslation();
t('common.cancel')                              // → "Cancel" / "Отмена"
t('chat.messagePlaceholder', { name: 'Alice' }) // → "Message Alice..."
t('incomingRequest.errors.SESSION_NOT_FOUND')
```

## Backend/Bot: Spring MessageSource

### Файлы

```
backend/src/main/resources/i18n/
├── messages.properties      # fallback (= _en)
├── messages_en.properties
└── messages_ru.properties
```

Использовать `ReloadableResourceBundleMessageSource` с `setDefaultEncoding("UTF-8")` — тогда кириллицу и эмодзи можно писать напрямую, без `\uXXXX`.

### `I18nConfig.java`

```java
@Configuration
public class I18nConfig {
    @Bean
    public MessageSource messageSource() {
        var source = new ReloadableResourceBundleMessageSource();
        source.setBasename("classpath:i18n/messages");
        source.setDefaultEncoding("UTF-8");
        source.setFallbackToSystemLocale(false);
        return source;
    }
}
```

### `BotMessageService.java`

```java
@Service
@RequiredArgsConstructor
public class BotMessageService {
    private final MessageSource messageSource;

    public String get(String key, String languageCode, Object... args) {
        return messageSource.getMessage(key, args, key, resolveLocale(languageCode));
    }

    private Locale resolveLocale(String languageCode) {
        if (languageCode == null) return Locale.ENGLISH;
        return switch (languageCode) {
            case "ru" -> new Locale("ru");
            default   -> Locale.ENGLISH;
        };
    }
}
```

Получить язык в боте: `update.getMessage().getFrom().getLanguageCode()`
