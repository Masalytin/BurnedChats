## Описание

Кнопка «Сжечь комнату» с подтверждением; отправка BURN_ROOM; при ответе или при получении ROOM_BURNED — удалить ключ комнаты из keyStore, переход на список комнат (или главную).

## Критерии приёмки

- [ ] Кнопка в UI управления комнатой (только владелец).
- [ ] Подтверждение: «Вы уверены? Все данные комнаты будут уничтожены.»
- [ ] После BURN_ROOM или входящего ROOM_BURNED: keyStore.remove(roomKey(roomId)); навигация на /rooms или home.

## Зависимости

- P2-4.3.2 (BURN_ROOM), P2-4.3.1 (UI).

## Заметки

- Обработка ROOM_BURNED на всех клиентах участников — такой же сброс keyStore и навигация.
