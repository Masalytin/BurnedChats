## Описание

В списке сообщений комнаты показывать, кто отправил: nickname/username (без раскрытия лишних метаданных). Опционально: статусы доставки/прочтения по желанию (можно отложить).

## Критерии приёмки

- [ ] В каждом сообщении отображается отправитель (senderTgId → username/firstName из кеша или из payload).
- [ ] Свои сообщения визуально отличаются (как в 1-to-1).
- [ ] Доставка/прочтение: опционально для Phase 2.

## Зависимости

- P2-4.2.2 (RoomChatRoom), UserService/кеш пользователей.

## Заметки

- senderTgId уже есть в EncryptedMessage для комнаты (добавляется сервером при relay).
