## Описание

Redis ключ `invite:{token}`: roomId, createdBy (ownerTgId), expiresAt, maxUses (опционально). InviteTokenRepository: create(roomId, ownerTgId, ttl, maxUses?), get(token), use(token), delete(token).

## Критерии приёмки

- [ ] token — криптостойкий (например 32 байта hex).
- [ ] TTL по expiresAt или фиксированный (например 7 дней).
- [ ] get(token) возвращает InviteToken или empty; при maxUses — декремент при использовании.

## Зависимости
