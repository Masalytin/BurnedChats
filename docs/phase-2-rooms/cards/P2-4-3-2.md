## Описание

STOMP BURN_ROOM(roomId): может вызвать только владелец. Удалить room, room_members, все invite токены комнаты, room_keys, messages комнаты; уведомить всех участников событием ROOM_BURNED(roomId); участники очищают keyStore и закрывают экран комнаты.

## Критерии приёмки

- [ ] Проверка: principal == owner комнаты.
- [ ] Удаление: RoomRepository.delete, RoomMembersRepository — удалить ключ, InviteTokenRepository — удалить все токены комнаты, RoomKeysRepository — удалить ключи комнаты, MessageRepository для roomId (messages:{roomId}).
- [ ] Рассылка ROOM_BURNED всем участникам (в т.ч. владельцу).

## Зависимости

- P2-1.1.2, P2-1.1.3, P2-2.1.1, P2-3.1.3, MessageRepository для комнат.

## Заметки

- Обратный индекс member_rooms:{tgId} очистить для всех участников.
