## Описание

Корректная обработка истечения: инвайт-токен и заявка имеют TTL; при истечении возвращать ошибку. Продление TTL комнаты при активности (отправка сообщения, вход участника) — чтобы активные комнаты не удалялись.

## Критерии приёмки

- [ ] При использовании invite token проверять expiresAt; при истечении — INVITE_EXPIRED.
- [ ] Заявки с TTL 24ч; при истечении не показывать владельцу.
- [ ] При SEND_ROOM_MESSAGE и при успешном JOIN — RoomRepository.extendTtl(roomId) (например +30 дней).
