## Описание

Backend: по запросу владельца генерировать новый invite token и возвращать ссылку. STOMP GET_INVITE_LINK(roomId) → ответ INVITE_LINK(url или token). Проверка, что вызывающий — владелец комнаты.

## Критерии приёмки

- [ ] Только ownerTgId комнаты может запрашивать ссылку.
- [ ] URL формата https://t.me/BotName/app?startapp=invite_{token} (или аналог для Mini App).
- [ ] Ответ в /queue/invite-link.
