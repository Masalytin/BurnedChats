## Описание

Relay зашифрованных сообщений в комнату: SEND_ROOM_MESSAGE(roomId, encryptedMessage). Проверить, что отправитель — участник комнаты; отправить сообщение всем подписчикам топика/очереди комнаты (topic/room/{roomId}); сохранить в messages:{roomId} для offline доставки (аналог messages:{sessionId}).

## Критерии приёмки

- [ ] MessageMapping SEND_ROOM_MESSAGE; проверка room_members содержит senderTgId.
- [ ] Подписчики: /topic/room/{roomId} или /user/queue для каждого участника (если нужна персонализация).
- [ ] Сохранение в Redis messages:{roomId} с TTL (например 24 ч); при подключении участника — выдача непрочитанных (SYNC_ROOM_MESSAGES).
- [ ] Событие NEW_ROOM_MESSAGE(roomId, message) участникам.

## Зависимости

- P2-1.1.3 (RoomMembersRepository), P2-3.1.3 (комната существует).

## Заметки

- Формат message тот же EncryptedMessage + senderTgId для отображения «кто отправил» без раскрытия содержимого.
