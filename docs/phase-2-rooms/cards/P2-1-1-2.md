## Описание

Реализовать RoomRepository (Java): save, findById, delete, extend TTL для ключа `room:{roomId}`.

## Критерии приёмки

- [ ] `save(Room room)` — сохранение/обновление, установка TTL.
- [ ] `findById(String roomId)` — возврат Mono&lt;Room&gt; или Mono.empty().
- [ ] `delete(String roomId)` — удаление ключа.
- [ ] `extendTtl(String roomId, Duration ttl)` — продление TTL.
- [ ] Использовать ReactiveRedisTemplate (Hash или JSON сериализация).
