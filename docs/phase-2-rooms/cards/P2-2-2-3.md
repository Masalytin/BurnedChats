## Описание

STOMP: ACCEPT_ROOM_JOIN(roomId, senderTgId) и REJECT_ROOM_JOIN(roomId, senderTgId). Вызывать может только владелец комнаты. При accept — добавить пользователя в room_members, удалить заявку; уведомить пользователя (JOIN_APPROVED); при reject — удалить заявку и уведомить (JOIN_REJECTED).

## Критерии приёмки

- [ ] Проверка: principal == owner комнаты.
- [ ] Accept: RoomMembersRepository.add(roomId, senderTgId); удалить заявку; отправить senderTgId событие JOIN_APPROVED (roomId, далее по P2-3 — выдача ключа).
- [ ] Reject: удалить заявку; отправить JOIN_REJECTED.

## Зависимости

- P2-2.2.1 (RoomJoinRequestRepository), P2-1.1.3 (RoomMembersRepository).

## Заметки

- После JOIN_APPROVED на стороне ключей будет заниматься P2-3.
