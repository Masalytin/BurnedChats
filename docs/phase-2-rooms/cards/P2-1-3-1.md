## Описание

Реализовать RoomService.createRoom(ownerTgId, salt, passwordProofHash, joinMode): генерация roomId, сохранение комнаты в Redis, добавление владельца в room_members, возврат roomId (и опционально первый invite token).

## Критерии приёмки

- [ ] roomId — UUID v4.
- [ ] Room сохраняется через RoomRepository; владелец добавляется в RoomMembersRepository.
- [ ] joinMode: by_password | by_request.
- [ ] Возврат RoomCreatedDto(roomId, inviteToken?) для использования в STOMP ответе.

## Зависимости

- P2-1.1.2 (RoomRepository), P2-1.1.3 (RoomMembersRepository), P2-1.2.2 (принимаемые параметры).

## Заметки

- Invite token может генерироваться в P2-2; здесь можно вернуть только roomId.
