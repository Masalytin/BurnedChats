## Описание

На frontend при создании комнаты: сгенерировать симметричный групповой ключ (AES); для каждого участника (пока только владелец) сохранить ключ в keyStore. При добавлении участника: шифровать групповой ключ публичным ключом нового участника (ECDH или RSA); формировать key bundle для отправки через сервер.

## Критерии приёмки

- [ ] Генерация groupKey (Web Crypto, AES-256).
- [ ] Хранение в keyStore по ключу roomId (или roomId:groupKey).
- [ ] Функция encryptGroupKeyForPeer(groupKey, peerPublicKey) → ciphertext (или key bundle).
- [ ] Интеграция с созданием комнаты: после ROOM_CREATED сохранить groupKey для владельца.

## Зависимости

- P2-1.3.3 (создание комнаты), P2-3.1.1 (протокол).

## Заметки

- Новый участник при JOIN_APPROVED получит key bundle и расшифрует групповой ключ (P2-3.2.1/2.3).
