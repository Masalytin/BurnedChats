## Описание

Участник (не владелец) может выйти из комнаты: кнопка «Выйти из комнаты»; backend LEAVE_ROOM(roomId) — удаление из room_members, инициация rekey (ротация группового ключа), уведомление остальным ROOM_REKEY и участнику LEFT_ROOM.

## Критерии приёмки

- [ ] Frontend: кнопка «Выйти» в меню комнаты (скрыта для владельца).
- [ ] STOMP LEAVE_ROOM(roomId); проверка: не владелец.
- [ ] RoomMembersRepository.remove(roomId, tgId); вызов rekey (P2-3.2.2); отправить LEFT_ROOM вызывающему, ROOM_REKEY остальным.
- [ ] У вышедшего: очистка keyStore для roomId, переход на список комнат.

## Зависимости

- P2-3.2.2 (rekey), P2-4.3.2 (удаление из room_members).

## Заметки

- Владелец «сжигает» комнату (BURN_ROOM), а не «выходит»; при желании можно добавить «Передать владельца» позже.
