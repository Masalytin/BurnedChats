## Описание

Хранить участников комнаты в Redis: ключ `room_members:{roomId}` (Set tgId). Реализовать RoomMembersRepository.

## Критерии приёмки

- [ ] `room_members:{roomId}` — Set строк (Telegram ID участников).
- [ ] TTL синхронизирован с комнатой или без TTL (удаляется при BURN_ROOM).
- [ ] RoomMembersRepository: add(roomId, tgId), remove(roomId, tgId), getMembers(roomId), isMember(roomId, tgId).

## Зависимости

- P2-1.1.1 (модель комнаты).

## Заметки

- При создании комнаты владелец сразу добавляется в room_members.
