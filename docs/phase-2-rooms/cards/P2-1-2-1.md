## Описание

На фронтенде реализовать деривацию «proof» из пароля: генерировать salt (crypto.getRandomValues), затем KDF (PBKDF2 через Web Crypto API или Argon2id при наличии wasm) — salt + password → proof. Proof и salt отправляются на сервер; пароль никогда не отправляется.

## Критерии приёмки

- [ ] Функция `derivePasswordProof(password: string): Promise<{ salt: string, proof: string }>`.
- [ ] Salt 16+ байт, proof фиксированной длины (например 32 байта), оба в Base64.
- [ ] При проверке входа: тот же KDF на клиенте (salt с сервера + введённый пароль) → proof сравнивается с тем, что отправляется на сервер (или сервер считает hash(proof) и сравнивает с сохранённым).
- [ ] Документировать алгоритм в SECURITY.md.

## Зависимости

- Нет.

## Заметки

- Конфиденциальность: сервер хранит только salt + hash(proof) или proof (при rate limit на перебор). Предпочтительно хранить только производную, не обратимую к паролю.
