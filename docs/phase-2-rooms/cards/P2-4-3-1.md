## Описание

UI для владельца комнаты: кнопка «Пригласить» (копировать ссылку / GET_INVITE_LINK), «Заявки» (переход к списку заявок), «Участники» (список участников комнаты), «Сжечь комнату» (подтверждение и вызов BURN_ROOM).

## Критерии приёмки

- [ ] В шапке или меню комнаты (только для владельца): Пригласить, Заявки, Участники, Сжечь комнату.
- [ ] Пригласить: запрос GET_INVITE_LINK, отображение/копирование ссылки.
- [ ] Заявки: экран из P2-2.2.5.
- [ ] Участники: список tgId/username (GET_ROOM_MEMBERS или из состояния).
- [ ] Сжечь: диалог подтверждения → BURN_ROOM.

## Зависимости

- P2-2.1.2 (GET_INVITE_LINK), P2-2.2.5 (заявки), P2-1.1.3 (участники), P2-4.3.2 (BURN_ROOM).

## Заметки

- Объединить в один экран «Управление комнатой» с табами или списком пунктов.
