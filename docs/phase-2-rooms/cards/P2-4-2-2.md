## Описание

Компонент RoomChatRoom — аналог ChatRoom для roomId: подписка на топик комнаты, загрузка группового ключа из keyStore по roomId, отображение сообщений (расшифровка групповым ключом), ввод и отправка (SEND_ROOM_MESSAGE с шифрованием групповым ключом).

## Критерии приёмки

- [ ] Подписка на /topic/room/{roomId} или аналог; получение NEW_ROOM_MESSAGE.
- [ ] keyStore.get(roomKey(roomId)) → groupKey; при отсутствии — запрос KEY_BUNDLE или переход на экран «Нет доступа».
- [ ] MessageList + MessageInput; шифрование/дешифрование тем же AES-GCM с groupKey.
- [ ] Отправка SEND_ROOM_MESSAGE при вводе сообщения.

## Зависимости

- P2-3.2.3 (keyStore для roomId), P2-4.2.1 (relay).

## Заметки

- Переиспользовать компоненты MessageList, MessageInput с пропсом sessionId vs roomId и ключом из разного источника.
