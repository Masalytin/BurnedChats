## Описание

Экран для владельца комнаты: список заявок на вход (от кого, когда). Подписка на очередь заявок по комнатам владельца; кнопки «Принять» / «Отклонить» для каждой заявки. Отправка ACCEPT_ROOM_JOIN / REJECT_ROOM_JOIN.

## Критерии приёмки

- [ ] При открытии комнаты владельцем — загрузка списка заявок (STOMP GET_ROOM_JOIN_REQUESTS или в составе ROOM_INFO).
- [ ] Подписка на обновления (новая заявка приходит в реальном времени).
- [ ] Карточка заявки: username/firstName, кнопки Принять / Отклонить.
- [ ] После действия — обновление списка и уведомление заявителю (на бэкенде).

## Зависимости

- P2-2.2.3 (ACCEPT/REJECT), backend GET_ROOM_JOIN_REQUESTS или аналог.

## Заметки

- Можно объединить с «Участники» в одном экране управления комнатой.
