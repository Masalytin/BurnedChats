## Описание

При принятии заявки (ACCEPT_ROOM_JOIN): владелец/система инициирует выдачу ключа новому участнику. Владелец на frontend формирует key bundle (групповой ключ, зашифрованный публичным ключом нового участника); отправка через STOMP (SEND_KEY_BUNDLE или сервер relay); новый участник получает событие KEY_BUNDLE и расшифровывает групповой ключ.

## Критерии приёмки

- [ ] После ACCEPT владелец получает событие или запрос на формирование key bundle для newMemberTgId.
- [ ] Владелец запрашивает публичный ключ нового участника (или он уже в заявке); шифрует groupKey; отправляет на сервер для доставки участнику.
- [ ] Участник в очереди получает KEY_BUNDLE(roomId, encryptedKeyBundle); расшифровывает и сохраняет в keyStore.

## Зависимости

- P2-2.2.3 (ACCEPT), P2-3.1.2 (шифрование для peer), обмен публичными ключами для комнаты (можно упростить: один раз при заявке отправить свой publicKey).

## Заметки

- Обмен публичными ключами: при REQUEST_JOIN_ROOM клиент может приложить свой publicKey; владелец при accept шифрует groupKey и отправляет.
