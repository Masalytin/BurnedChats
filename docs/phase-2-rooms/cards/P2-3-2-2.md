# P2-3.2.2 — Ротация группового ключа при выходе участника

## Описание

При выходе участника из комнаты (или удалении владельцем): сгенерировать новый групповой ключ (rekey); зашифровать его для каждого оставшегося участника; разослать key bundles; уведомить всех о смене ключа (ROOM_REKEY). Старый ключ больше не используется.

## Критерии приёмки

- [ ] Инициатор rekey — владелец (или любой участник при своём выходе? решить в протоколе).
- [ ] Новый groupKey; для каждого оставшегося участника — encrypt(key, participantPublicKey); рассылка.
- [ ] Событие ROOM_REKEY(roomId, newEpoch или флаг); участники обновляют keyStore.
- [ ] Сообщения после rekey шифруются уже новым ключом.

## Зависимости

- P2-3.1.2 (шифрование для участников), P2-3.1.3 (Redis keys при хранении), P2-4.3.4 (выход участника).

## Заметки

- У вышедшего участника не должно быть доступа к новому ключу; старые сообщения он расшифровать не может (forward secrecy для группы).
