## Описание

STOMP: GET_MY_ROOMS — возвращает список комнат, где текущий пользователь участник или владелец. Ответ ROOM_LIST: массив { roomId, role (owner|member), createdAt, lastActivity? }.

## Критерии приёмки

- [ ] По principal (tgId) найти все roomId из room_members (например обратный индекс member_rooms:{tgId} или scan по ключам room_members:* с SISMEMBER).
- [ ] Для каждой комнаты — роль (owner если ownerTgId==tgId), createdAt; опционально lastActivity.
- [ ] Ответ в /queue/room-list.

## Зависимости

- P2-1.1.3 (RoomMembersRepository), P2-1.1.2 (RoomRepository для метаданных).

## Заметки

- Обратный индекс: при add(roomId, tgId) также SADD member_rooms:{tgId} roomId; при remove — SREM. Упрощает GET_MY_ROOMS.
