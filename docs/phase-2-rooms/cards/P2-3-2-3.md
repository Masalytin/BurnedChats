## Описание

На frontend при входе в комнату (после JOIN_APPROVED): подписка на очередь; при получении KEY_BUNDLE(roomId, encryptedKeyBundle) — расшифровать своим приватным ключом, получить groupKey; сохранить в keyStore по roomId; перейти к экрану чата комнаты.

## Критерии приёмки

- [ ] Обработчик события KEY_BUNDLE в socket/handlers.
- [ ] Расшифровка (ECDH или гибрид: симметричный ключ из ECDH с владельцем + encrypted group key).
- [ ] keyStore.set(roomKey(roomId), groupKey); переход в RoomChatRoom.
- [ ] Обработка ROOM_REKEY: обновить ключ в keyStore для roomId.

## Зависимости

- P2-3.2.1 (KEY_BUNDLE с бэкенда), P2-2.2.4 (вход по ссылке).

## Заметки

- Приватный ключ участника для комнаты: может быть тот же, что для 1-to-1, или отдельная пара для групповых комнат (решить в протоколе).
