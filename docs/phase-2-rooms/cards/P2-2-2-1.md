## Описание

Redis: заявки на вход в комнату. Вариант — `room_join_request:{roomId}` List или Set с данными заявки (senderTgId, createdAt); или ключ `room_join_request:{roomId}:{senderTgId}`. TTL 24 часа. RoomJoinRequestRepository: add, listByRoom(roomId), remove(roomId, senderTgId).

## Критерии приёмки

- [ ] Владелец может получить список заявок по roomId.
- [ ] Удаление заявки при accept/reject.
- [ ] TTL чтобы старые заявки исчезали.
