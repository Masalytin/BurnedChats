## Описание

Ввести в Redis ключи и структуру данных для комнаты: `room:{roomId}` с полями ownerTgId, salt, passwordProofHash, joinMode, createdAt, TTL.

## Критерии приёмки

- [ ] Ключ `room:{roomId}` (roomId — UUID v4).
- [ ] Поля: `ownerTgId`, `salt` (Base64), `passwordProofHash` (Base64/hex), `joinMode` (`by_password` \| `by_request`), `createdAt` (ms), опционально `nameEncrypted`.
- [ ] TTL комнаты (например 30 дней), продлевается при активности.
- [ ] Документировать схему в DATA_MODELS.md (Phase 2).

## Зависимости

- Нет (первая задача спринта).

## Заметки

- joinMode: по паролю — кто знает ссылку и пароль, входит сразу; по заявкам — после одобрения владельцем.
