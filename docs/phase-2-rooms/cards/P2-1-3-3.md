## Описание

Экран/модальное окно «Создать комнату»: ввод пароля, выбор режима входа (по паролю / по заявкам), вызов crypto (derivePasswordProof), отправка CREATE_ROOM, отображение результата (roomId и ссылка приглашения при наличии).

## Критерии приёмки

- [ ] Поля: пароль (повтор для проверки), режим — «Вход по паролю» / «Только по заявкам».
- [ ] По Submit: derivePasswordProof(password), отправка CREATE_ROOM через STOMP.
- [ ] После ROOM_CREATED: показать успех и кнопку «Скопировать ссылку» / переход в комнату.
- [ ] Обработка ошибок (слабый пароль, сеть).

## Зависимости

- P2-1.2.1 (KDF), P2-1.3.2 (STOMP).

## Заметки

- Минимальные требования к паролю (длина, сложность) опционально; можно подсказки в UI.
