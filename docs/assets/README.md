## Wanted captures

| File | Content |
|------|---------|
| `chat.png` | 1:1 chat with the burn timer visible |
| `room.png` | Password-protected room join screen |
| `fingerprint.png` | Visual fingerprint (MITM) verification ceremony |
| `demo.gif` (optional) | 10–20 s flow: create room → join → send message → burn |

## Guidelines

- Capture inside Telegram (mobile or desktop Mini App frame) — it reads better
  than a bare browser tab.
- Portrait phone aspect ratio, ~1080 px wide is plenty; compress PNGs.
- Use throwaway test accounts and rooms only. **Never capture real chats,
  keys, QR codes, wallet addresses with funds, or bot tokens.**
- After adding files, uncomment the `## Screenshots` section in the root
  `README.md`.
